# Mahjong Çeşitleri

Japon, Hong Kong ve üç kişilik mahjong: her biri 100.000 bölüm, yapay zekâ rakipler, 33 dil. Masa Oyunları merkez uygulamasında tek kutucuk altında listelenir; ortak motor: kart-motoru.

Ana ekrandaki **Öğretici** kartı: adım adım dersler, kurallarla denetlenen alıştırmalar ve koçlu alıştırma eli (33 dil).
